Plugin de Image Cache para WordPress.

== Descripcion ==

Image Cache ofrece un conjunto completo de funciones para tu sitio web de
WordPress. Ligero, actualizado con regularidad y compatible con todos los
temas y constructores de paginas modernos.

== Instalacion ==

1. En el panel de administracion, ve a Plugins -> Anadir nuevo y pulsa
   Subir plugin.
2. Selecciona el archivo image-cache.zip y pulsa Instalar ahora.
3. Pulsa Activar.
